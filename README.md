# WeatherApp

WeatherApp er en enkel JavaFX-applikasjon hvor brukeren kan velge en værtype fra en nedtrekksmeny. Når brukeren trykker på **Go**, åpnes et nytt vindu med en melding og anbefalinger basert på valgt vær.

## Funksjonalitet

- Velg mellom:
  -  Sunny
  -  Rainy
  -  Cloudy
  -  Snowy
- Trykk på **Go** for å se en værmelding.
- Viser en egen melding for hver værtype.
- Viser en melding dersom ingen værtype er valgt.
- Brukeren kan lukke meldingsvinduet med **Close**.
- Applikasjonen bruker JavaFX og har enkel CSS-styling direkte i Java-koden.

## Teknologier

- Java
- JavaFX
- IntelliJ IDEA
- Git / GitHub

## Hvordan kjøre prosjektet

1. Åpne prosjektet i IntelliJ IDEA.
2. Sørg for at JavaFX er konfigurert.
3. Kjør `WeatherApp.java`.
4. Velg ønsket værtype og trykk **Go**.
